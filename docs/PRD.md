# 微信公众号AI助手 — 产品需求文档（PRD）

> 版本：v0.1 | 日期：2025-07-25 | 作者：产品经理

---

## 1. 项目信息

| 字段 | 值 |
|------|------|
| Language | 中文 |
| Programming Language | Vite + React 18 + MUI + Tailwind CSS |
| Project Name | wechat-ai-assistant |
| 类型 | Chrome 浏览器扩展（Manifest V3） |

**原始需求复述**：仿照"壹伴小插件"开发一款聚焦 AI 能力的 Chrome 浏览器插件，注入微信公众平台后台 `mp.weixin.qq.com`，提供 AI 写作、标题优化、排版、内容诊断等核心功能。后端使用本地服务 `127.0.0.1`，AI 能力对接 OpenAI API / 本地大模型。

---

## 2. 产品定义

### 产品目标

**让每一位公众号运营者都拥有一个 7×24 在线的 AI 内容合伙人**——从选题、写作、标题、排版到数据复盘，AI 全链路辅助，显著降低内容创作门槛、提升产出质量和效率。

### 目标用户

| 用户类型 | 特征 | 核心痛点 |
|----------|------|----------|
| 个人自媒体 | 1-2 人运营，内容产出压力大 | 写作慢、标题没感觉、排版耗时 |
| 企业新媒体团队 | 有内容规范但效率低 | 排版重复劳动、违规风险高、数据复盘靠直觉 |
| 代运营机构 | 多账号高频产出 | 模板复用困难、内容同质化、质量难控 |

## 4. 需求池

### P0 — 必须实现（MVP 核心）

| ID | 功能 | 描述 | 验收标准 |
|----|------|------|----------|
| P0-01 | AI 智能写作 | 在编辑器侧边栏提供 AI 写作面板，支持长文/短文模式，输入主题/关键词后 SSE 流式输出初稿，可一键插入编辑器 | 输入主题后 5s 内开始输出；生成内容可插入编辑器且格式正确 |
| P0-02 | AI 标题优化 | 对当前文章标题进行 AI 评分（0-100），提供 3-5 个优化备选标题，支持一键替换 | 评分 3s 内返回；备选标题可一键应用 |
| P0-03 | AI 排版 | 一键将当前编辑器内容按预设风格重新排版（字号、行距、缩进、配色、引用样式等），支持多种风格切换 | 排版后格式统一无错乱；支持 ≥3 种预设风格 |
| P0-04 | AI 内容诊断 | 读取近 N 篇已发布文章的阅读/点赞/分享数据，AI 生成内容策略报告（选题建议、发布时间、标题模式等） | 报告包含 ≥3 条可操作建议；数据采集自动完成 |
| P0-05 | 编辑器增强（基础） | 在微信编辑器中注入工具栏，提供快捷格式按钮：加粗/斜体/引用/分割线/代码块/图片居中/字号调节 | 按钮点击即生效；不与微信原生功能冲突 |
| P0-06 | Chrome 扩展基础架构 | Manifest V3 + Content Script 注入 + Background Service Worker + Popup/Side Panel + 本地后端通信 | 注入 mp.weixin.qq.com 正常工作；与本地服务通信正常 |

### P1 — 应该实现

| ID | 功能 | 描述 | 验收标准 |
|----|------|------|----------|
| P1-01 | 文章采集 | 浏览任意网页时，右键或点击扩展图标，将页面正文提取为 Markdown 保存到素材库 | 采集成功率 ≥90%（主流资讯网站）；保存到本地服务 |
| P1-02 | 数据看板 | 在侧边面板展示公众号近期数据概览：阅读量趋势、爆款文章 TOP5、粉丝增长等 | 图表可交互；数据实时从本地服务获取 |
| P1-03 | 违规检测 | 发布前 AI 扫描全文，标记敏感词/违规表述/广告法风险，给出修改建议 | 误报率 <10%；支持敏感词库自定义 |
| P1-04 | 模板管理 | 保存当前文章排版为模板，下次一键套用；支持模板分类、预览、删除 | 模板保存后可完整还原排版；支持 ≥20 个模板 |
| P1-05 | 本地后端服务 | Node.js/Python 本地服务，提供 AI 代理（对接 OpenAI API / 本地模型）、数据存储、微信 API 代理 | 本地服务启动后扩展可正常通信；API Key 安全存储 |

### P2 — 可以实现

| P2-02 | 多账号管理 | 支持切换多个公众号身份，不同账号独立配置 | 切换后数据隔离；配置不丢失 |

| P2-04 | 自定义 Prompt | 用户可自定义 AI 写作/标题的 Prompt 模板，保存复用 | 自定义 Prompt 生效；支持导入/导出 |

## 5. 与壹伴的差异化定位

| 维度 | 壹伴小插件 | 微信公众号AI助手 |
|------|-----------|----------------|
| **产品哲学** | 全功能工具箱（70+ 功能） | AI-First，每个功能都由 AI 驱动 |
| **核心价值** | 效率工具集合（排版、采集、数据…） | AI 内容合伙人（写作、诊断、策略） |
| **AI 深度** | AI 是附加功能 | AI 是产品灵魂，所有功能围绕 AI 展开 |
| **后端架构** | 云端 SaaS（api.yiban.io） | 本地服务 + 可选云 API，数据自主可控 |
| **用户心智** | "排版工具" | "AI 创作伙伴" |
| **商业模式** | 订阅制（功能解锁） | 本地免费 + AI 用量付费（按 Token） |
| **扩展性** | 功能堆叠 | 插件化 AI Skill，用户可自定义 Prompt |

**一句话差异**：壹伴是"瑞士军刀"，我们是"AI 内容合伙人"。

## 6. UI 设计草案

### 整体布局

```
┌─────────────────────────────────────────────────┐
│  微信公众平台后台 (mp.weixin.qq.com)              │
│ ┌──────────────────────┐ ┌─────────────────────┐│
│ │                      │ │   AI 助手侧边栏      ││
│ │   微信图文编辑器      │ │  ┌───────────────┐  ││
│ │                      │ │  │ 💬 AI 写作     │  ││
│ │   + 增强工具栏       │ │  │ 📊 内容诊断    │  ││
│ │   (Content Script    │ │  │ 🎯 标题优化    │  ││
│ │    注入)             │ │  │ 🎨 AI 排版     │  ││
│ │                      │ │  │ ⚠️ 违规检测    │  ││
│ │                      │ │  │ 📋 模板库      │  ││
│ │                      │ │  └───────────────┘  ││
│ └──────────────────────┘ └─────────────────────┘│
└─────────────────────────────────────────────────┘
```

### 关键交互

1. **侧边栏入口**：编辑器右侧固定 AI 助手按钮，点击展开/收起侧边面板
2. **AI 写作流**：输入主题 → 选择风格/长度 → SSE 流式输出 → 一键插入
3. **AI 排版流**：选择风格 → 预览效果 → 确认应用
4. **标题优化流**：点击标题区域 AI 图标 → 弹出评分+备选 → 一键替换

## 附录：技术约束备忘

- **Manifest V3**：Service Worker 无持久连接，需用 `chrome.storage` 管理状态
- **CSP 限制**：微信公众平台有严格 CSP，Content Script 需注意内联脚本限制
- **CSS 隔离**：所有注入 CSS 必须加统一前缀（如 `waa-`），避免与微信后台样式冲突
- **DOM 稳定性**：微信后台 DOM 结构可能随版本更新变化，选择器需容错
- **SSE 流式**：AI 写作/排版需通过 Background → Content Script 转发 SSE 流
